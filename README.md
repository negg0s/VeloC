# VeloC

VeloC (Velocity + C) - диалект системного программирования со строгой статической типизацией, компилируемый в нативный код через C++20 / Clang backend. Язык ориентирован на низколатентные и высокопроизводительные системы (HFT, игровые движки, runtime систем машинного обучения, потоковая обработка данных).

## Ключевые свойства

- Детерминированное управление памятью: арены (Arena), линейные аллокаторы, маркеры перемотки (Rewind Markers), Zero-Allocation структуры данных.
- Аппаратная векторизация: встроенные примитивы AVX2, FMA3, BMI2, SSE4.2 (SIMD операции для численных методов, тензорных вычислений и алгоритмов поиска).
- Предсказуемая кодогенерация: отсутствие скрытых аллокаций, отсутствие сборщика мусора, прямая трансляция в эффективный C++ код.
- Встроенные структуры: Eytzinger Cache-Friendly Search, SwissTable, RingBuffer, SoA контейнеры, SmallVector, Lock-Free MPSC очереди.
- Стандарты вычислений: дефолтный строгий режим IEEE-754 (без глобального fast-math), Kahan/Pairwise суммирование с ULP-гарантиями.

## Стек проекта

- Транслятор и тулчейн: Python 3.10+ (парсер, лексер, анализатор типов, PCH кэш, генератор кода).
- Бэкенд компиляции: Clang 18+ / GCC 13+ / MSVC 2022 (поддержка C++20).
- Заголовочный рантайм: C++20 (`include/veloc.h`, `include/veloc_core.h`, `include/veloc_numerics.h`).
- Архитектура: x86_64 (AVX2, FMA3, BMI2, SSE4.2).

## Требования к окружению

1. Python 3.10 или новее.
2. Clang с поддержкой C++20 (рекомендуется Clang из MinGW-w64 на Windows или системный Clang на Linux).
3. Процессор с поддержкой набора инструкций AVX2.

## Установка и настройка

Клонируйте репозиторий:

```bash
git clone https://github.com/USER/VeloC.git
cd VeloC
```

Проверьте доступность тулчейна:

```bash
python veloc.py --version
```

Вывод информации об аппаратных возможностях хоста:

```bash
python veloc.py hwinfo
```

## Основные команды

### Компиляция и запуск программы

```bash
python veloc.py run examples/hello.vc
```

### Сборка исполняемого файла

```bash
# Режим разработки
python veloc.py build examples/hello.vc -o hello.exe

# Режим максимальной оптимизации (-O3, native tune)
python veloc.py build examples/extreme_speed.vc --release -o extreme_speed.exe
```

### Запуск тестов

```bash
# Прогон базового набора тестов
python veloc.py test

# Запуск золотого тестового набора
python tests/test_golden.py
```

### Форматирование и проверка кода

```bash
# Форматирование исходников VeloC
python veloc.py fmt examples/hello.vc

# Статический анализ и проверка типов
python veloc.py check examples/hello.vc
```

### Запуск REPL

```bash
python veloc.py repl
```

### Очистка кэша сборки

```bash
python veloc.py clean --all
```

## Структура репозитория

```text
VeloC/
├── src/          # Исходный код компилятора, парсера, анализатора и тулчейна
├── include/      # Заголовочный рантайм VeloC (C++20 ядра, SIMD, аллокаторы)
├── examples/     # Примеры программ и витрины возможностей языка
├── tests/        # Наборы тестов (юнит-тесты, golden tests, семантические тесты)
├── benchmarks/   # Эталонные бенчмарки и профилирование производительности
├── docs/         # Документация, спецификация языка, архитектурные решения
├── apps/         # Прикладные программы и стресс-тесты на VeloC
└── veloc.py      # Основной интерфейс командной строки (CLI)
```

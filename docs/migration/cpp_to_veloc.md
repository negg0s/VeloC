# Руководство по миграции: C++ в VeloC

Это официальное практическое руководство для разработчиков, переходящих с C++ на VeloC.

---

## 1. Таблица соответствий концепций

| Концепция C++ | Эквивалент в VeloC | Описание и преимущества VeloC |
|---|---|---|
| `int x = 42;` | `let x = 42;` | Неизменяемая по умолчанию переменная |
| `int x = 42; x = 50;` | `let mut x = 42; x = 50;` | Явный маркер мутабельности `mut` |
| `int add(int a, int b) { ... }` | `pub fn add(a: i32, b: i32) -> i32 { ... }` | Четкая сигнатура, чистый вывод типов |
| `std::cout << x << std::endl;` | `println(f"{x}");` | Форматированные строки без перегрузки сдвигов |
| `std::optional<T>` | `Option<T>` | Встроенный тип с паттерн-матчингом и оператором `?` |
| `std::expected<T, E>` | `Result<T, E>` | Монадическая обработка ошибок с методом `.unwrap()` |
| `std::vector<T>` | `Vec<T>` / `Slice<T>` | Безопасная непрерывная память без скрытых аллокаций |
| `switch (val) { case ... }` | `match val { pat => expr }` | Мощный паттерн-матчинг по числам и строкам |
| `AOS struct { float x, y, z; }` | `soa struct Particle { x: f32, y: f32, z: f32 }` | Автоматическая генерация 8-wide AVX2 SoA структуры |
| `malloc` / `new` | `Arena`, `TrackingAllocator`, `StaticPool` | Детерминированные аллокаторы без фрагментации |

---

## 2. Постепенная миграция (Интероп C++ и VeloC)

VeloC компилируется непосредственно в чистый C++ через Clang 20, что дает **нулевую стоимость вызова** (zero-cost interop) между кодом на VeloC и существующими C++ библиотеками.

### Автоматический транслятор `veloc from-cpp`

Для быстрой миграции существующих модулей используйте CLI-команду:
```bash
python veloc.py from-cpp path/to/legacy.cpp -o src/migrated.vc
```

Инструмент автоматически преобразует функции, потоковый вывод `std::cout` в форматированные `println`, переменные в `let [mut]`, и маркирует нераспознанные участки комментариями `// TODO: veloc migration`.

# Руководства по переходу: Rust / Zig / Go / Python → VeloC

Краткий справочник соответствий и различий для разработчиков, приходящих из других языков программирования.

---

## 1. Rust → VeloC
* **Что похоже:**
  - Синтаксис объявления переменных `let` и `let mut`.
  - Модули `module`, функции `fn`, оператор обработки ошибок `?` (Try Operator), типы `Option<T>` и `Result<T, E>`.
  - Паттерн-матчинг `match` со стрелками `=>` и подстановочным знаком `_`.
  - Срезы памяти `Slice<T>` и `Span<T>`.
* **Что отличается:**
  - В VeloC нет тяжелого borrow checker во время компиляции; безопасность памяти обеспечивается контролируемыми аллокаторами (`Arena`, `TrackingAllocator`, `StaticPool`) и статическим анализом утечек стека (`veloc check`).
  - Прямой нулевой вызов C++ интринсиков и библиотек без тяжелых FFI-оберток.

---

## 2. Zig → VeloC
* **Что похоже:**
  - Аллокаторы передаются явно как первоклассная концепция языка (`TempAllocator`, `FixedPool`).
  - Принцип отсутствия скрытого потока управления (no hidden control flow).
  - Поддержка `no_std`/freestanding режима для встраиваемых систем (`veloc-embedded`).
* **Что отличается:**
  - Нативная поддержка SoA структур первого класса (`soa struct Name { ... }`) с автогенерацией выровненных AVX2 массивов.
  - Синтаксис ближе к Rust/TypeScript, чем к C-нотации Zig.

---

## 3. Go → VeloC
* **Что похоже:**
  - Простота синтаксиса и ориентированность на высокую скорость компиляции.
  - Понятные структуры данных и плоские массивы.
* **Что отличается:**
  - В VeloC **нет сборщика мусора (GC)** и пауз Stop-the-World.
  - Прямой доступ к SIMD-векторам AVX2/AVX-512 и FMA на уровне языка.

---

## 4. Python → VeloC
* **Что похоже:**
  - Форматированные f-строки `println(f"Hello {name}, x = {x * 2}")`.
  - Удобные срезы `for (let i in range(0, 10, 2))`.
  - Встроенный парсер JSON в стандартной библиотеке.
* **Что отличается:**
  - VeloC — статически типизированный компилируемый язык со скоростью выполнения в 50-100 раз выше Python.
  - Создание нативных бинарников `.exe` без интерпретатора.

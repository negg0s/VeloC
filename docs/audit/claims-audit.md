# Claims audit — что из документации подтверждается проверками

Проверка выполнена 2026-10-18 на этой машине (Windows 11 build 26200,
Python 3.12.8, Clang 20.1.3, 6C/12T CPU). Метод: запуск `python veloc.py ...`
и чтение кода. Утверждения, для которых нет воспроизводимого запуска/скрипта,
помечены как «неподтверждено» — они НЕ доказаны и НЕ опровергнуты здесь.
